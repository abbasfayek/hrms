  - جميع بنود السياسة المالية المؤجلة (Unpaid->Payroll, Half-Day,
    Early-Leave, Proration, ...) مؤجلة بالكامل إلى P2.2.

2) مواصفات قواعد العمل P2.1 (نطاق النزاهة فقط)

   أ) الحضور (Attendance)
      - يمنع تكرار سجل لنفس الموظف في نفس اليوم
        (تحت مفتاح employeeId + date).
      - updateAttendance تسمح بالتحرير مع الحفاظ على القاعدة أعلاه.
      - رفض checkout قبل checkIn (checkOut < checkIn).
      - رفض القيم السالبة: workingHours / lateMinutes / earlyDepartureMinutes.
      - رفض سجل لموظف غير موجود (employee_not_found).
      - رفض سجل لموظف بدون شركة/فرع أي بدون نطاق (no_scope).

   ب) الإجازات (Leaves)
      - رفض تداخل الإجازات القادمة (pending) أو المعتمدة (approved)
        لنفس الموظف (findOverlappingLeaves).
      - عند التعديل يتم استثناء السجل نفسه (excludeId) حتى لا يرفض
        تعديل الإجازة نفسها.
      - الإجازات المرفوضة (rejected) أو الملغاة (cancelled):
        مسموح حفظها متداخلة لأنها لا تستهلك رصيدًا ولا تحجب.
      - حالة cancelled جديدة: تعيد الرصيد للموظف (لا تُحتسب في
        المستخدمة)، ويُضاف زر إلغاء + تدقيق (audit).
      - رفض إجازة لموظف غير موجود / بدون نطاق / غير نشط
        (غير active/probation/on_leave).
      - رفض نطاق تاريخ غير صالح (end < start) أو عدد أيام <= 0.
      - نصف يوم: daysCount = 0.5 فقط عندما start == end
        (إجازة ليوم واحد)، ويُحسب 0.5 في رصيد الإجازة السنوية.
      - رصيد الإجازة السنوية عند إرسال الطلب:
        المعلقة (pending) تُحجز من الباقي، ويُرفض الطلب إذا تجاوز الرصيد.

   ج) الإجازات الساعية (Hourly Leaves)
      - حصة الموظف الساعية تُطبَّق على جميع الحالات (وليس المعتمد فقط).
      - الساعات المعلقة (pending) تُحجز من الباقي:
        remainingHours = max(0, quota - used - pending).
      - رفض سجل لموظف غير موجود / بدون نطاق.

   د) عزل النطاق (Multi-company / branch)
      - موظف branch_hr يرى فقط سجلات فرعه في الموظفين والحضور
        والإجازات والساعات.
      - إصلاح إضافي: setActiveUser يعيد الفلتر إلى 'all' عند عودة
        مدير عام بعد خروج موظف scoped (كان الفلتر يبقى عالقًا).

4) قواعد الحماية الجديدة (رسائل الخطأ - recordErrorText)
   - duplicate_attendance : سجل حضور مكرر لنفس الموظف واليوم.
   - checkout_before_checkin: وقت الانصراف قبل وقت الدخول.
   - negative_value       : قيمة سالبة غير مسموحة.
   - employee_not_found   : الموظف غير موجود.
   - no_scope             : الموظف بدون شركة/فرع (بدون نطاق).
   - inactive_employee    : الموظف غير نشط (لا يمكن إضافة إجازة).
   - invalid_range        : نطاق تاريخ غير صالح / أيام <= 0.
   - leave_overlap        : تداخل مع إجازة قادمة أو معتمدة.
