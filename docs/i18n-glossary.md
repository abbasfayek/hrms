# HR and Payroll Localization Glossary

This glossary is the source of truth for bilingual UI wording. New i18n keys
must use the complete contextual phrases below rather than assembling labels
from individual translated words.

| English | Arabic | Usage |
| --- | --- | --- |
| Employee | الموظف | Person employed by the organization |
| Employee ID | الرقم الوظيفي | Internal employee identifier |
| Department | القسم | Organizational department |
| Job Title | المسمى الوظيفي | Employee position title |
| Basic Salary | الراتب الأساسي | Fixed base pay |
| Housing Allowance | بدل السكن | Housing component of pay |
| Transport Allowance | بدل النقل | Transport component of pay |
| Payroll | الرواتب | General payroll workspace |
| Payroll Run | مسير الرواتب | A specific monthly payroll calculation |
| Approve Payroll | اعتماد مسير الرواتب | Payroll approval action |
| Recalculate | إعادة احتساب | Recompute a calculated record |
| Leave Management & Balances | إدارة الإجازات والأرصدة | Leave workspace title |
| Leave Balance | رصيد الإجازة | Leave entitlement balance |
| Remaining Leave Balance | رصيد الإجازة المتبقي | Available leave after consumption |
| Attendance | الحضور | Time and attendance tracking |
| Overtime | العمل الإضافي | Overtime work and entitlement |
| Absence | الغياب | Unscheduled absence record |
| Late Arrival | التأخير | Late arrival attendance exception |
| End-of-Service Benefits | مستحقات نهاية الخدمة | EOSB settlement amounts |
| Social Insurance | التأمينات الاجتماعية | Statutory insurance contribution |
| Registered Wage | الأجر المسجل | Wage registered for social insurance |
| WPS | WPS | Official Wage Protection System acronym |
| GOSI | GOSI | Official social-insurance acronym |
| EOSB | EOSB | Official end-of-service acronym |
| IBAN | IBAN | International bank account identifier |
